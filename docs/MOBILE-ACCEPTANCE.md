# Wujie Hub 0.1.17 ID迁移候选版多平台验收

维护者于2026-10-29明确要求“你先发布，后面我统一测试”，随后指定仓库和插件ID统一为wujie-hub，并选择重新建独立条目。0.1.17据此提交新条目，旧0.1.16保留直到新条目可用。Android/iOS及最低版本实机验收仍待完成，不代表已有通过结果。授权记录绑定当前版本，不能自动跨版本复用。

目标：Windows、macOS、Linux、Android、iOS/iPadOS；最低 Obsidian 1.12.0。1.12 使用旧设置页路径；1.13+ 使用声明式设置页。两条路径复用相同界面和操作实现。

## 设备与安装

在 Android 和 iPhone/iPad 上各使用一个独立测试库。记录设备型号、系统版本、Obsidian 完整版本号；至少一台设备或独立桌面测试实例必须运行 1.12.x。不要为测试降级日常使用的库或覆盖账号配置。

将测试包解压到测试库的 `<配置目录>/plugins/wujie-hub/`；仅替换 main.js、manifest.json、styles.css，保留已有 data.json 和其他文件。启用后打开管理器设置页。测试库不得包含需要保密的账号、笔记或同步资料。

## 每台移动设备的检查项

1. 设置页三部分完整显示；搜索、下拉、按钮在窄屏及横屏可用，离开后再次进入无异常。
2. 搜索一个支持移动端的社区插件，确认安装后保持禁用；到 Obsidian 官方界面启用，检查可正常加载。
3. 使用测试插件执行启用状态下更新，确认启用状态和原 data.json、其他非发行文件保持不变。更换配置目录的测试库至少验证一次。
4. 选择一个仅桌面端插件，确认安装被拒绝，现有插件文件及配置未被改动。
5. 在独立测试夹具中测试下载失败及加载失败恢复，记录原代码和启用状态是否恢复；不要破坏真实使用中的插件。
6. 无界同步仅在没有真实账号、且始终禁用的测试库中验证清单读取、摘要校验、用户明确确认后的代码快照、版本切换和离线回退。此项不代表同步功能实机验收。

反馈格式：设备/系统、Obsidian版本、配置目录、上述各项通过/失败、失败时的完整提示。真实反馈确认后再写入 docs/validation/platform-acceptance.json，不能用自动测试结果代替设备结果。iPadOS 可按 iOS 平台记录并注明具体型号和系统。

macOS/Linux 的 Node 自动测试通过只证明测试逻辑跨系统运行，不等同于 Obsidian 实机验收；需要分别补充对应应用中的同类安装、更新和恢复结果。
